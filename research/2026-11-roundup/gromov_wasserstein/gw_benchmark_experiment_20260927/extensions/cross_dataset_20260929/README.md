## Measurements

Primary outputs are full feasible GW loss versus actual solver-plus-current-output-repair time, with preparation, diagnostics, validation, serialization and launcher process time separate. Retain raw marginal residuals, repair displacement, outer updates, sketch probes, KL inner iteration counts, tolerance misses and memory. Actual checkpoint observations are not interpolated.

For SNARE, report symmetric coupling true-match top1 accuracy with uniform tie credit, symmetric true-match rank fraction, and total mass on the known pairing. A uniform coupling receives top1=1/n and rank fraction=.5. Rank fraction is based on coupling weights, not embedding-space FOSCTTM. Correspondence labels do not enter updates or parameter selection. Their evaluation is charged to diagnostics, outside solver time, and uses no random draws.

Common loss targets per instance are .99/.97/.95/.90 times its pilot product-start initial full rounded GW loss. The fractional rule is fixed here; numerical targets are frozen from that initial observation before tuning. For each target report the first observed attainment, the preceding observed nonattainment when available, and right censoring when never observed. Sparse observations are not exact hitting times, and nonmonotone trajectories can cross between observations.

A separate descriptive profiling companion runs the selected configurations from product start with seed400 for 220 fixed updates; discard the first20 timings and retain200. It times probe generation, sketch-gradient kernel, row-FW update or transport-KL proximal solve, and remaining update work using synchronized wall time. Extra synchronization changes throughput; profiling does not supply or replace primary timing comparisons. No correspondence labels are used by profiling. Profile outputs are small JSON records, not another set of saved dense couplings.

Five stochastic repeats on each fixed input characterize optimizer variation, not uncertainty over biological populations. The two SNARE subsets are nested.
