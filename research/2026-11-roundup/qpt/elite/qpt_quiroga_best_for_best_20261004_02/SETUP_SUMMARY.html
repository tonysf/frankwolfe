Critical analysis rule: method-native penalized objectives are retained as diagnostics but are never differenced, pooled, or used as a cross-method score. Paired differences are limited to recovery/physical metrics: loss or RMSE, fidelity, TP violation, and the gate indicator. Shared comparison contract

  • Identical data/channel instance, active rows, observations, serialized U0, rank, precision, logical row budget, and checkpoints.
  • Common noiseless recovery gate: fidelity ≥ 0.99, full-design RMSE ≤ 1e-6, and normalized TP violation ≤ 1e-3.
  • FRAMES retains its operator-norm-ball domain; printed adaFGD remains unconstrained. This domain difference must be reported.
  • Logical row epochs are the progress axis, not a compute-equivalence claim. Wall time, LMO work, and spectral-norm work remain separate.

Order and freezing

  1. Run n=2 full 128 rows, then n=2 subset 96. The subset gate uses RMSE on all 128 rows.
  2. Select one configuration per method on calibration instances using the predeclared gate-first rule.
  3. Write and hash an immutable selection manifest containing both selected config IDs. Validation runs use those frozen IDs and cannot rerank them.
  4. Run held-out instances only with the same selection-manifest hash, selected config IDs, budgets, checkpoints, gate, and source commit.
  5. Proceed to n=4 full 8,192 rows only after the n=2 launcher, archive, accounting, and aggregation checks pass.

Previous corrected-design runs remain preserved as exploratory or ablation evidence. The old shared-penalty bundle is preserved unchanged but is superseded for primary claims; it may be reported only as a matched-penalty ablation. Legacy high-qubit QPT_BFW runs remain valid only for their local-Pauli sensing design.
